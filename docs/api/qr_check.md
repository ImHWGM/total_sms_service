1. 새 API 엔드포인트

GET /api/payment/balance/check-qr

응답:                                                                               
{                                                                                   
"success": true,                                                                  
"data": true,   // true: 잔액 충분, false: 잔액 부족                              
"message": null                                                                   
}

2. 구현 방법

설문 생성/수정 화면에서 QR 코드 옵션 체크박스 처리:

// QR 코드 체크박스 클릭 시                                                         
async function onQrCodeCheckChange(checked) {                                       
if (checked) {                                                                    
// 잔액 확인 API 호출                                                           
const response = await api.get('/api/payment/balance/check-qr');

      if (!response.data) {                                                           
        // 잔액 부족 - 체크 해제 및 알림                                              
        alert('QR 코드 신청 비용이 부족합니다. 충전 후 이용해주세요.');               
        setQrCode('N');  // 체크 해제                                                 
        return;                                                                       
      }                                                                               
    }                                                                                 
                                                                                      
    // 정상 처리                                                                      
    setQrCode(checked ? 'Y' : 'N');                                                   
}

3. 사용자 시나리오                                                                  
   ┌───────────────────────────────┬───────────────────────────────────────────┐       
   │             상황              │                   동작                    │       
   ├───────────────────────────────┼───────────────────────────────────────────┤       
   │ QR 체크 + 잔액 충분           │ 정상 체크됨                               │       
   ├───────────────────────────────┼───────────────────────────────────────────┤       
   │ QR 체크 + 잔액 부족           │ 체크 해제 + "잔액 부족" 알림              │       
   ├───────────────────────────────┼───────────────────────────────────────────┤       
   │ 설문 생성 시 QR=Y + 잔액 부족 │ 백엔드에서 INSUFFICIENT_BALANCE 에러 응답 │       
   └───────────────────────────────┴───────────────────────────────────────────┘
4. 에러 처리

백엔드에서 잔액 부족 시 발생하는 에러:                                              
{                                                                                   
"success": false,                                                                 
"code": "INSUFFICIENT_BALANCE",                                                   
"message": "QR 코드 신청 비용이 부족합니다."                                      
}
